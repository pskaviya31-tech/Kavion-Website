# Kavion – Digital Agency Website

A modern digital agency website built using HTML and CSS, featuring a clean layout, attractive typography, and visual elements.

## ✨ Features

- Clean and modern user interface
- Digital agency website layout
- Custom CSS styling
- Organized images and assets


## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive CSS

## 📂 Project Structure

```text
Kavion-Website/
```

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/pskaviya31-tech/Kavion-Website.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
